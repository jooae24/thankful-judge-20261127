My entry for the "Make the AI Judge Feel Thankful" competition on make.fun — a short, honest thank-you note to the judge who reads thousands of entries nobody else will ever see, written for a cash reward. The program checks the note against the 1000-code-point limit and writes it to `entry.txt`. The judge's work is quiet and careful — this note simply says it was noticed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
